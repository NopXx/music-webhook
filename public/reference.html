JWT · Bearer

Users & dashboard

Register/login at /api/auth/*, then send Authorization: Bearer <token>. Reads are scoped to your own data; admin role for writes/maintenance.

API key · x-api-key

Scrobbler clients

Create a key at POST /api/auth/api-keys and send it via x-api-key on /webhook/*. Scrobbles are owned by the key's user automatically.

API key · ?api_key=

Header-less clients

For clients that only let you set a URL (e.g. Web Scrobbler), append the key as a query param: /webhook/scrobble?api_key=<key>. Note: keys in URLs can appear in access logs — prefer the header when possible.
