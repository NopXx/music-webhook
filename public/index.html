Music Webhook API

บันทึกประวัติการฟังเพลงจาก Web Scrobbler / ListenBrainz / Apple Music ลง MongoDB พร้อม enrich จาก Spotify & Apple Music — ข้อมูลแยกตามผู้ใช้แต่ละคน

Log in / Register API Docs

เริ่มใช้งานยังไง

1

สร้างบัญชี / เข้าสู่ระบบ

สมัครที่ /login — บัญชีใหม่เป็น role viewer เห็นเฉพาะข้อมูลของตัวเอง

2

สร้าง API key

ใช้ token หลัง login เรียกสร้าง key (โชว์ครั้งเดียว เก็บไว้ให้ดี):

curl -X POST /api/auth/api-keys \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"label":"my-laptop"}'
3

ตั้งค่า scrobbler

ชี้ webhook ของ Web Scrobbler / client มาที่ /webhook/scrobble พร้อม header x-api-key: <key> — scrobble จะผูกกับบัญชีคุณอัตโนมัติ

4

ดูสถิติ

เรียก /api/stats, /api/tracks ฯลฯ (login ผ่าน cookie หรือ Bearer token) — เห็นเฉพาะการฟังของคุณ

ระบบ Auth มี 2 ชั้น

JWT · Bearer

สำหรับคน / dashboard

Register/login ได้ JWT แล้วส่ง Authorization: Bearer (หรือผ่าน cookie). ใช้กับ analytics, now-playing และงาน admin

API key · x-api-key

สำหรับ scrobbler client

เครื่องที่ยิง webhook ไม่มี session — ใช้ API key ที่ผูกกับบัญชี ส่งผ่าน header x-api-key
